# Solid Starts 심층 분석

> 유형: 이유식·음식 도입·알레르기 정보 앱/웹  
> 조사일: 2026-11-08  
> 공식: https://www.solidstarts.com/app/

# 0. Evidence Card

공식 페이지에서 확인:
- 500+ foods
- 연령별 제공 형태 사진/영상
- 알레르겐 단계별 가이드
- 첫 100가지 음식 개인화 계획
- 300+ 가족용 레시피
- 음식/선호/반응 기록
- 소아과·알레르기·feeding therapy·영양 전문가 참여

근거 수준: A

---

# 1. 한 문장 정의

Solid Starts는 **'이 음식을 아기에게 어떻게 안전하게 줄까?'라는 매우 구체적인 순간의 질문을 검색 가능한 음식 데이터베이스, 연령별 시각 가이드, 기록, 알레르기 정보로 해결하는 전문 육아 지식 시스템**이다.

---

# 2. 가장 강한 사용 순간

부모의 질문은 보통 매우 즉각적이다.

> 사과를 7개월 아기에게 어떻게 잘라주지?

일반 검색:
- 블로그 여러 개
- 서로 다른 조언
- 광고
- 출처 확인 필요

Solid Starts:
```
음식 검색
→ 월령
→ 제공 형태
→ 사진/영상
→ 주의점
→ 기록
```

**Search-to-action**이 매우 짧다.

---

# 3. 음식 DB의 구조

좋은 이유식 데이터는 단순 레시피 DB가 아니다.

각 음식에:
- 연령별 제공 형태
- 크기
- 질감
- 준비 방법
- 안전 주의
- 영양
- 알레르기 관련 정보
- 실제 사진/영상

이 연결되어야 한다.

특히 손과 비교한 크기 사진처럼 **텍스트보다 빠른 시각적 판단**이 중요하다.

---

# 4. 기록 구조

공식 페이지는:
- 먹어본 음식
- favorite
- reaction

기록을 지원한다고 설명한다.

이를 확장하면 매우 좋은 개인 데이터 모델이 된다.

```
Food
├─ first exposed
├─ exposures
├─ preparation
├─ acceptance
└─ reactions
```

---

# 5. 첫 100가지 음식

'100 Foods' 같은 목표는 이유식의 다양성을 게임처럼 진행하게 만들 수 있다.

장점:
- 무엇을 줄지 고민 감소
- 다양성 시각화
- 부모에게 진척감

주의:
- 숫자 달성 자체가 목적이 되면 안 됨
- 아이의 개인 상황과 의료 조언이 우선

---

# 6. 알레르기 영역

이 영역은 특히 고위험이다.

좋은 시스템은:
- 일반 교육
- 노출 기록
- 반응 기록
- 응급증상 시 의료 도움 안내

까지만 명확히 하고, 앱이 독자적으로 알레르기를 진단해서는 안 된다.

반응을 기록할 때는 최소:
- 음식
- 시간
- 증상
- 시작 시각
- 의료기관 이용 여부

가 유용하다.

---

# 7. 연령별 UX

Solid Starts는 0~4개월, 5~6개월, 7~9개월, 10~12개월, 12개월+처럼 시기별로 정보를 다르게 배치한다.

이것은 육아 전체 시스템에서도 적용해야 한다.

같은 '음식' 메뉴라도:
- 3개월: 이유식 준비 정보
- 6개월: 첫 음식
- 9개월: 질감/자기주도 식사
- 12개월+: 가족 식사

처럼 목적이 달라진다.

---

# 8. 강점

- 매우 명확한 특정 문제
- 검색 의도가 행동과 가까움
- 사진/영상 중심
- 전문가 근거를 제품 가치로 사용
- 정보와 개인 기록 연결
- 월령별 맥락 제공

---

# 9. 리스크

- 국가별 식품·의료 권고 차이
- 고위험 알레르기 정보를 일반화할 위험
- 구독 콘텐츠와 필수 안전정보 경계
- 부모가 식품 개수 목표에 집착할 가능성

안전 관련 핵심 정보는 유료벽 뒤에 과도하게 숨기지 않는 것이 바람직하다.

---

# 10. 가져올 패턴

## Object-centered Search
육아 정보가 주제별 기사보다 **사물/상황 검색**으로 접근 가능해야 한다.

예:
- 계란
- 바나나
- 열
- 기침
- 뒤집기

## Visual Instruction
말보다 사진 한 장이 빠른 영역을 찾는다.

## Record from Content
정보를 본 화면에서 바로:
```
[오늘 먹였어요]
```
로 기록한다.

## Content → Personal History
일반 음식 정보가 내 아이의 섭취 이력으로 이어진다.

# 결론

Solid Starts의 핵심은 **일반 지식 데이터베이스와 내 아이 기록을 같은 객체를 중심으로 연결하는 것**이다.

육아 플랫폼에서도 '음식', '백신', '발달기술' 같은 객체를 중심으로 **정보 → 행동 → 개인기록** 흐름을 만들 수 있다.
