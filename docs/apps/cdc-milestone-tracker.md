# CDC Milestone Tracker 분석

> 유형: 공공기관 발달 마일스톤 앱  
> 운영: U.S. CDC  
> 조사일: 2026-11-08  
> 공식: https://www.cdc.gov/act-early/milestones-app/

# 0. Evidence Card

공식 CDC 페이지 기준 기능:
- 2개월~5세 발달 마일스톤
- 일러스트 체크리스트
- 사진·영상 예시
- 조산아 교정연령
- 발달 촉진 팁/활동
- 우려 시 행동 안내
- PDF/email 요약
- 진료 방문 메모
- appointment reminder
- 다자녀
- 개인 식별정보를 CDC가 수집/공유하지 않는다고 명시

근거 수준: A

---

# 1. 한 문장 정의

CDC Milestone Tracker는 **부모가 발달을 관찰하고 기록하며, 무엇이 마일스톤인지 시각적으로 이해하고, 우려가 있을 때 의료진과 대화할 수 있도록 만드는 공공형 발달 모니터링 도구**다.

---

# 2. 상업 앱과 다른 목표

상업 앱은:
- 리텐션
- 구독
- 개인화
- 콘텐츠 소비

를 함께 고려한다.

CDC 앱의 중심 목표는:
```
관찰
→ 조기 인지
→ 필요 시 전문가 상담
```

이다.

따라서 **무엇을 하지 않는가**도 중요하다.

---

# 3. 사진·영상 예시의 가치

'혼자 앉는다' 같은 문장만 보면 부모마다 해석이 다르다.

사진·영상은:
- 어떤 행동을 의미하는지
- 어느 정도 수행하면 되는지

를 더 정확히 이해하게 한다.

발달 기록에서는 텍스트 체크박스보다 **behavior exemplar**가 중요하다.

---

# 4. 조산아 교정연령

공식 기능에 corrected age가 포함된다.

이는 데이터모델 관점에서 매우 중요하다.

```
birth_date
```

만으로 모든 발달 화면을 계산하면 부족할 수 있다.

필요한 경우:
- 예정일
- 재태기간
- 교정연령

맥락이 들어간다.

---

# 5. 'Act Early' 흐름

좋은 발달 시스템은 빨간 점수만 보여주면 안 된다.

필요한 구조:

```
관찰
→ 아직 보이지 않음
→ 무엇을 더 관찰할지
→ 의료진에게 무엇을 말할지
→ 요약 자료
```

CDC 앱의 PDF/email summary는 이 흐름에 특히 적합하다.

---

# 6. 진료 연결

Milestone summary를 의료진과 공유할 수 있다.

이는 매우 좋은 **Clinical Handoff** 패턴이다.

육아 앱에서 데이터를 쌓는 것보다 중요한 질문:

> 병원에 갔을 때 이 데이터를 30초 안에 설명할 수 있는가?

---

# 7. 안전한 한계 표시

CDC는 앱이 표준화되고 검증된 발달 선별검사를 대체하지 않는다고 명시한다.

이 문구가 중요하다.

일반 체크리스트:
```
monitoring
```

검증된 선별도구:
```
screening
```

진단:
```
diagnosis
```

세 단계를 혼동하면 안 된다.

---

# 8. 개인정보

공식 페이지는 개인을 식별할 수 있는 정보를 CDC가 수집/공유하지 않는다고 설명한다.

공공 보건 앱에서 이는 핵심 신뢰 요소다.

발달 정보는 장기간 민감할 수 있으므로:
- 최소 수집
- 로컬 처리
- 명확한 export
- 명확한 삭제

가 특히 중요하다.

---

# 9. 강점

- 출처가 명확
- 의료적 한계를 명확히 표시
- 영상 예시
- 조산아 고려
- 의료진 공유용 요약
- 불안을 상업적으로 이용할 동기가 낮음

---

# 10. 한계

- 매우 강한 개인화 추천 서비스는 아님
- 국가가 다르면 검진·지원기관 정보는 그대로 적용 불가
- 한국에서는 K-DST와 국내 영유아 검진 체계를 우선해야 함

따라서 제품 패턴은 가져오되 의료기준은 한국 공식 기준으로 현지화해야 한다.

---

# 11. 가져올 패턴

## Evidence Example
마일스톤마다 사진/영상 예시.

## Doctor-ready Summary
체크 데이터를 PDF 등 한 장으로 요약.

## Clear Boundary
'이 도구가 무엇을 할 수 없나'를 명확히 표시.

## Concern Path
우려를 보여주고 끝내지 않고 다음 행동으로 연결.

---

| 생활 기록 | 1 |

| 개인정보 원칙 | 5 |

# 결론

CDC Milestone Tracker는 '발달 앱을 안전하게 만드는 법'을 연구하기 좋은 기준점이다.

특히:
**관찰 → 예시 → 요약 → 의료진 대화**
흐름과 **체크리스트는 진단이 아니라는 명확한 경계**가 핵심이다.
