# 1. 한 문장 정의

FamilyAlbum은 **아기 사진을 단순 저장하는 서비스를 넘어, 촬영일과 아이 나이를 기준으로 자동 정리하고 가족만 공유하며 시간이 지나면 회고 콘텐츠로 다시 생성하는 '가족 성장 메모리 시스템'**이다.

---

# 2. 해결하는 문제

아이가 태어나면 사진 양이 폭발한다.

일반 사진앱의 문제:
- 부모 휴대폰에 흩어짐
- 조부모에게 계속 메신저로 전송
- 같은 사진을 여러 번 보냄
- 몇 개월 때 사진인지 나중에 찾기 어려움
- 가족별로 원본 보유 여부가 다름

FamilyAlbum은 이 문제를 **아이 중심 공유공간**으로 바꾼다.

---

# 3. 기본 기능

공식 도움말 기준:

- 사진/영상 업로드
- 무료 무제한 업로드
  - 기본 무료 동영상은 2분 이내
- 아이 연령에 맞춰 월별 자동 정리
- 초대한 가족만 열람
- 가족 전원 공개 / 관리자 한정 공개
- 최대 100명 참여
- 댓글
- 즐겨찾기
- 포토북 자동 제안
- 실물 상품
- 자동 1초 동영상

프리미엄에서는 더 긴 동영상, PC 업로드, 추가 성장 기록 및 회고 기능 등이 확장된다.

---

# 4. 가장 중요한 설계: 아기를 중심으로 한 앨범

일반 클라우드:

```
내 계정
└─ 사진
```

FamilyAlbum:

```
아이 앨범
├─ 관리자
├─ 관리자
├─ 가족 멤버
├─ 조부모
└─ 기타 초대 가족
```

이 구조는 육아 서비스 전체에 적용할 수 있다.

**아기가 중심 엔터티이고 보호자는 권한을 가진 참여자**다.

---

# 5. 관리자와 멤버 권한

공식 도움말에서는 관리자와 멤버 역할이 명확히 분리된다.

관리자는:
- 가족 초대/연결 해제
- 공개범위 관리
- 업로드/수정/삭제
- 댓글/다운로드 제어 등

멤버는 관리자 설정에 따라 기능이 제한된다.

이것은 매우 중요한 패턴이다.

육아 앱에서 모든 가족에게 동일 권한을 주면:
- 기록 오류
- 민감한 의료정보 노출
- 사진 무단 다운로드
- 의도하지 않은 공유

문제가 발생할 수 있다.

---

# 6. 자동 정리

사진을 '2026-12'처럼만 정리하는 것이 아니라 **아기의 나이 맥락**으로 다시 보여주는 것이 중요하다.

예:

```
생후 1개월
생후 2개월
생후 3개월
```

육아 데이터는 달력 시간(calendar time)보다 **아기 나이(age-relative time)**가 더 의미 있는 경우가 많다.

이 원칙은 사진뿐 아니라 발달·검진·접종에도 적용된다.

---

# 7. Memory Loop

FamilyAlbum의 가장 뛰어난 구조는 기록을 다시 되살리는 것이다.

```
사진 업로드
↓
월별 자동정리
↓
가족 반응
↓
3개월/연간 자동 영상
↓
과거의 오늘
↓
포토북
```

대부분의 기록 앱은 데이터를 '묻어버린다'.

FamilyAlbum은 시간이 지날수록 과거 데이터를 **다시 소비할 이유**를 만든다.

---

# 8. 1초 동영상

사진과 영상 일부를 자동으로 연결해 성장 영상을 만든다.

이 기능의 핵심은 영상 편집 기술이 아니다.

**입력 없이 생성되는 보상**이라는 점이다.

사용자는 평소 사진만 올렸는데 몇 달 후 감정적으로 가치 있는 결과물을 받는다.

```
낮은 추가 입력
+
높은 감정적 보상
```

매우 좋은 retention 구조다.

---

# 9. 슬라이드쇼 / 과거의 오늘

과거 같은 날짜의 사진을 다시 보여준다.

이 기능도 같은 패턴이다.

```
기존 데이터
→ 새로운 맥락
→ 재방문
```

새 콘텐츠를 계속 만들어야 하는 서비스보다 훨씬 효율적이다.

---

# 10. 커머스 연결

포토북·DVD 등은 서비스 사용 흐름과 자연스럽게 연결된다.

나쁜 커머스:
> 육아앱 안에 unrelated 상품 배너

좋은 커머스:
> 이미 쌓인 사진 → 포토북 제작

즉 **사용자 데이터가 자연스럽게 물리적 결과물로 이어진다**.

---

# 11. 강점

## A. 가족 공유 문제를 정확히 해결
메신저 전송을 대체한다.

## B. 연령 기반 자동정리
육아 맥락에 최적화되어 있다.

## C. 권한 시스템
관리자/멤버 역할이 명확하다.

## D. 기록에 감정적 보상을 준다
자동 영상과 회고가 대표적이다.

## E. 장기 가치
사진은 아이가 커져도 계속 쌓인다.

---

# 12. 약점과 리스크

## A. 미디어 집중
건강·생활 기록과 직접 통합되지는 않는다.

## B. 아동 사진의 민감성
초대·다운로드·공개범위 UX는 매우 중요하다.

## C. 가족관계 변화
초대된 가족의 접근 회수와 과거 다운로드 문제는 완전히 해결하기 어렵다.

## D. 실물 상품 업셀
감정적 데이터를 수익화하기 때문에 과한 판매 유도는 신뢰를 훼손할 수 있다.

---

# 13. 가져올 패턴

## Pattern 1 — Age-relative timeline

```
2027년 6월
```

보다

```
생후 6개월
```

을 핵심 맥락으로 사용한다.

---

## Pattern 2 — Automatic Memory Reward

기록 데이터를 자동으로:
- 영상
- 월간 요약
- 1년 전 오늘
- 성장 카드

로 바꾼다.

---

## Pattern 3 — Permission by Content Type

예:
- 생활 기록: 부모
- 의료 기록: 부모만
- 사진: 가족
- 특정 사진: 관리자만

공개범위를 데이터 종류별로 분리할 가치가 있다.

---

# 14. 육아 통합 시스템에 주는 시사점

건강 기록만 있는 앱은 부모에게 '업무 도구'처럼 느껴질 수 있다.

FamilyAlbum의 메모리 루프를 결합하면:

```
오늘의 기록
→ 건강/생활 패턴
+
오늘의 사진
→ 성장 추억
```

이 두 축이 균형을 이룬다.

# 결론

FamilyAlbum의 가장 큰 교훈은 **과거 기록을 다시 가치 있게 만드는 시스템**이다.

육아 서비스는 기록할 때만 유용해서는 안 된다.

시간이 지난 뒤:

> "이때 이렇게 작았구나"

를 자동으로 만들어줄 수 있어야 장기 사용성이 생긴다.
