> 유형: AI 음성·자연어 기반 육아 기록  
> 조사일: 2026-11-08  
> Google Play: https://play.google.com/store/apps/details?id=com.pew_pew.momi

# 0. Evidence Card

Google Play 공식 등록정보에서 2026-10-28 기준 확인되는 기능:
- 음성 육아 기록
- 수유·수면·기저귀 등의 자연어 분석
- 구조화 결과 확인 후 저장
- 버튼 직접 기록
- 마지막 수유/오늘 수면 요약
- 성장 리포트
- 예방접종 안내

근거 수준: B — 공식 앱스토어 등록정보

---

# 1. 한 문장 정의

모미는 **아이를 안고 있어 손이 부족한 순간에 말로 기록하고, AI가 자연어를 수유·수면·기저귀 등의 구조화 데이터로 바꾸는 '입력 마찰 제거형' 육아 기록 앱**이다.

---

# 2. 왜 매우 중요한 사례인가

기존 육아 트래커의 가장 큰 약점은 사용자가 매번 앱을 열고 정확한 항목을 눌러야 한다는 것이다.

전통적 흐름:
```
앱 열기
→ 수유 탭
→ 분유
→ 시간
→ 용량
→ 저장
```

음성 AI:
```
"5분 전에 분유 120 먹었어"
→ AI 구조화
→ 확인
→ 저장
```

육아 상황에서는 이 차이가 매우 크다.

---

# 3. 좋은 AI 사용 방식

특히 중요한 것은 **AI가 바로 저장하지 않고 정리된 내용을 확인하고 저장하는 흐름**이다.

```
자연어
→ 구조화 후보
→ 사용자 확인
→ 원자료 저장
```

이 방식은 hallucination 위험을 줄인다.

예:

입력:
> "아까 10분쯤 먹고 방금 잠들었어."

AI 후보:
```
모유수유
시작 14:12
지속 10분

수면
시작 14:29
```

시간이 불명확하면 저장 전에 물어보거나 수정 가능해야 한다.

---

# 4. 음성 기록이 특히 좋은 영역

## 매우 적합
- 분유 120ml
- 수면 시작/종료
- 기저귀
- 유축
- 목욕
- 산책
- 간단한 메모

## 주의 필요
- 약 복용량
- 체온
- 알레르기 증상
- 예방접종 완료

고위험 데이터는 AI 해석 결과를 반드시 명시적으로 확인해야 한다.

---

# 5. AI parser의 데이터 모델

AI가 이해해야 할 기본 요소:

```
intent
entity
quantity
unit
time
duration
confidence
```

예:
```json
{
  "intent": "bottle_feeding",
  "amount": 120,
  "unit": "ml",
  "time": "now-5m",
  "confidence": 0.94
}
```

최종 저장 데이터에는 AI confidence보다 **사용자가 확인한 실제 값**이 들어가야 한다.

---

# 6. 여러 사건 한 문장 처리

육아에서는 한 번에 여러 일을 말할 수 있다.

> "분유 100 먹고 기저귀 갈았는데 소변이었고 지금 잠들었어."

좋은 AI는 이를 세 이벤트로 분리한다.

```
Feeding
Diaper
Sleep
```

Huckleberry의 AI logging과 함께 비교할 가치가 큰 영역이다.

---

# 7. 가장 중요한 실패 처리

AI 입력 서비스는 성공률보다 **실패했을 때 덜 귀찮은가**가 중요하다.

나쁜 UX:
> 인식할 수 없습니다. 다시 말해주세요.

좋은 UX:
```
분유 기록으로 이해했어요.
[120] ml
[14:20]

시간을 정확히 이해하지 못했어요.
[지금] [직접 수정]
```

부분적으로 이해한 데이터는 보존한다.

---

# 8. 강점

- 육아 기록에서 매우 실제적인 문제를 해결
- 한 손/무손 사용 가능성
- 여러 이벤트를 자연어로 입력 가능
- 버튼식 기록과 병행 가능
- AI를 의료 조언보다 저위험 입력 자동화에 우선 사용

---

# 9. 리스크

## 시간 표현
'아까', '좀 전에', '한 시간쯤' 같은 표현의 불확실성.

## 단위 오류
120ml를 1200ml 등으로 잘못 이해하면 통계가 크게 왜곡된다.

## 고위험 기록
약·체온 등은 자동확정 금지.

## 음성 개인정보
음성 원본이 서버로 전송/보관되는지 명확한 정책이 필요하다.

---

# 10. 가져올 패턴

## Voice Capture Everywhere
홈 중앙 또는 위젯에서 즉시 음성 시작.

## Confirmation Card
AI 결과를 한 카드에서 빠르게 검토.

## Multi-event Parsing
한 문장을 여러 이벤트로 분리.

## Confidence-aware UX
불확실한 필드만 사용자에게 확인.

## Hybrid Input
음성만 강요하지 않고 버튼 기록도 유지.
