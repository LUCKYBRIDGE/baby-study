# MOMI(모미) — 공식 앱스토어/Play Store 직접 관찰

> 관찰일: 2026-11-08  
> 근거: Google Play / Apple App Store 공식 등록정보  
> 레벨: A3

## 1. 매우 빠르게 확장 중인 신생 서비스

2026년 하반기 업데이트 기록에서 다음 기능들이 짧은 기간 안에 추가/확장되고 있습니다.

- 음성 AI 기록
- 빠른 홈 기록
- 임신 기록
- 월간 성장 리포트
- AI 일기
- AI 대화
- 가족앨범
- AI Studio
- 위시리스트/선물
- 위젯/기록 서랍

따라서 현재 기능수는 많지만 제품 구조가 아직 빠르게 변하는 단계로 봐야 합니다.

## 2. 핵심 기록 흐름

공식 설명에서 실제로 강조하는 흐름:

```
자연어/음성
→ AI가 시간·종류·양 파싱
→ 구조화 결과 보여줌
→ 사용자가 확인
→ 저장
```

특히 **확인 후 저장**이 중요합니다.

AI 결과가 곧바로 원자료가 되지 않습니다.

## 3. 임신기 기록

공식 설명에서 임신기에는:
- 태동
- 혈당
- 혈압
- 헤모글로빈
- 수면 등

을 기록합니다.

출산 후에는:
- 수유
- 유축
- 수면
- 기저귀
- 체온
- 성장
- 영양제/예방접종 등

으로 데이터 타입이 전환됩니다.

즉 제품 자체가 lifecycle state machine입니다.

## 4. AI 일기

공식 스토어 설명에서 AI가 다듬은 일기와 원문을 함께 보관합니다.

이는 생성형 AI 제품에서 좋은 설계입니다.

```
Original
+
AI Transformation
```

을 분리해 사용자의 실제 기억을 AI 결과가 덮어쓰지 않습니다.

같은 원칙을:
- 음성 transcript
- 구조화 record
- AI summary

에도 적용할 수 있습니다.

## 5. 월간 리포트

최근 업데이트에서는 아기 월령에 맞춘 성장 리포트와 그래프가 추가되었습니다.

즉 단순 event log에서:
```
Timeline
→ Category
→ Monthly summary
```
로 확장 중입니다.

## 6. 가족앨범

사진/영상과 가족 반응을 함께 제공하며, 기록 앱에서 memory platform으로 확장합니다.

여기서 필요한 권한 분리:
- 육아 기록
- 건강 기록
- 가족 사진

을 서로 다른 공유범위로 관리해야 합니다.

## 7. AI Chat/Studio 확장

AI 사용 지점이:
- 기록
- 일기
- 질문
- 이미지

까지 빠르게 늘고 있습니다.

장점:
- 하나의 구독 이유를 여러 화면에 제공

위험:
- 핵심 기록 UX가 AI 기능 허브에 묻힐 수 있음
- 건강 질문에서 모델 과신 가능성
- 아동 이미지/건강정보의 외부 모델 처리 이슈

## 8. 개인정보 관련 직접 확인

Google Play 데이터 안전 섹션에서는:
- 일부 데이터 수집/공유 가능성
- 전송 중 암호화
- 삭제 요청

등을 표시합니다.

다만 실제 AI 처리의 세부사항은 다음을 추가 검증할 필요가 있습니다.
- 음성 원본 보관
- 모델 공급자
- 학습 사용 여부
- 아동 이미지 보관
- retention 기간

## 9. 수익모델

App Store에서 AI Pro/AI Max 형태의 구독이 보입니다.

즉 구독 가치가:
- 예측
보다
- 생성형 AI 기능 접근량/범위

에 더 가깝습니다.

## 10. 직접 관찰 핵심

MOMI에서 가장 참고할 부분은 화려한 AI 기능 수가 아니라:

**AI가 만든 후보를 사용자가 확인해야만 authoritative record가 되는 입력 구조**

입니다.

반대로 현재 제품은 기능 확장 속도가 매우 빨라 IA 복잡도와 안정성은 장기 관찰이 필요합니다.
