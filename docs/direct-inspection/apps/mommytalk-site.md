# 마미톡 — 공식 사이트/공식 커뮤니티 직접 관찰

> 관찰일: 2026-11-08  
> 근거: 마미톡 공식 홈페이지 + 공식 커뮤니티 콘텐츠  
> 레벨: A1

## 1. 공식 홈페이지의 첫 가치

첫 화면에서 가장 강하게 내세우는 것은:
- 고화질 초음파 영상
- 가족 공유
- AI 기반 아기 모습 콘텐츠
- 임신/육아 시기별 정보

입니다.

즉 진입점이 일반 콘텐츠 검색이 아니라 **병원에서 발생한 실제 초음파 산출물**입니다.

## 2. 병원→앱 연결

마미톡의 매우 중요한 구조:

```
Hospital ultrasound
→ App
→ Parent
→ Family
```

이것은 일반 B2C 육아앱과 다른 distribution model입니다.

앱 설치를 광고로 설득하기보다 의료기관에서 실제 사용할 이유가 생깁니다.

## 3. 전문가 신뢰 레이어

공식 사이트는:
- 산부인과
- 소아청소년과
- 관련 전문의/전문단체 감수

를 전면에 둡니다.

건강 콘텐츠 플랫폼에서 중요한 메타데이터:
- 작성/감수 주체
- 업데이트일
- 적용대상
- 출처

를 서비스 신뢰의 일부로 사용한 사례입니다.

## 4. 실제 육아 기록 깊이 — 기존 분석 수정

공식 커뮤니티의 마미톡 기능 안내를 직접 확인하면 출산 후 기록 기능이 생각보다 깊습니다.

확인되는 원터치 기록 범주:
- 모유
- 유축
- 분유
- 수면
- 소변/대변
- 이유식
- 체온
- 약
- 병원 방문
- 메모

그리고 기록 후:
- 일간 통계
- 주간 통계

를 자동 제공합니다.

따라서 마미톡을 단순 "임신 콘텐츠 앱 + 얕은 육아기록"으로 보면 부정확합니다.

실제 구조는:

```
Clinical entry point
→ Pregnancy lifecycle
→ Postpartum daily tracker
→ Statistics
→ Community
```

에 더 가깝습니다.

## 5. 출산 전후 상태전환

출산이 발생하면 핵심 과업이 완전히 바뀝니다.

### 임신
- 초음파
- 주수
- 검사
- 산모 정보

### 육아
- 수유
- 수면
- 배변
- 체온/약
- 성장
- 병원

마미톡은 하나의 계정에서 이 전환을 이어갑니다.

## 6. 커뮤니티

공식 커뮤니티에는 게시글마다 아기 월령/일수와 주제 맥락이 강하게 드러납니다.

즉:
- 일반 육아 커뮤니티
보다
- **현재 시기 기반 경험 공유**

성격이 강합니다.

전문가 콘텐츠와 사용자 경험담은 반드시 시각적으로 구분해야 합니다.

## 7. 구조적 강점

1. 의료기관 기반 acquisition
2. 감정적으로 강한 초음파 asset
3. 시기별 전문가 정보
4. 출산 후 daily tracker
5. 자동 통계
6. 커뮤니티/쇼핑으로 장기 관계 확장

## 8. 위험

- 의료 신뢰와 커머스가 같은 플랫폼에 존재
- 커뮤니티 경험담의 과도한 일반화
- 기능이 많아질수록 홈 복잡도 증가
- AI 아기 이미지와 실제 의료영상 의미 혼동 가능성

## 9. 직접 관찰 핵심

마미톡은 단순 임신앱이 아니라 **오프라인 병원 접점에서 사용자를 획득해 출산 후 tracking 플랫폼으로 전환시키는 구조**입니다.

그리고 실제 기록 기능은 기존 예상보다 더 완성도가 높은 편이어서 BabyTime/Huckleberry와도 비교할 가치가 있습니다.
