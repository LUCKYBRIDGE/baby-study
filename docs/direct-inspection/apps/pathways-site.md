# Pathways.org — 직접 사이트 IA/Tracking 관찰

> 관찰일: 2026-11-08  
> 근거: 공식 Today / Play / Track / Activities  
> 레벨: A1

## 1. 실제 상단 IA

Pathways 웹서비스의 핵심 하단/주요 동선은:

```
Home
Today
Play
Track
Explore
```

입니다.

이는 단순 의료정보 사이트와 전혀 다릅니다.

## 2. Track 아래 실제 도구

사이트 메뉴에서 직접 확인:

- Milestone Tracker
- Tummy Timer
- Diaper Tracker
- Feeding Tracker

즉 developmental knowledge service이면서 동시에 **basic baby tracker**를 포함합니다.

## 3. Today 화면

Today에서 확인되는 카드:

- Tummy Time progress
- Activities 0/3
- Massage+
- Feeding
- Diaper
- Today recommendation
- Baby's Week
- Parent Pathways
- Baby's Progress
- New This Week

즉 Today는:
```
Today Action
+
Weekly Habit
+
Development Progress
+
Parent Education
```
을 한 화면에 조합합니다.

## 4. Baby's Progress

실제 Today 페이지에서:
- Motor
- Sensory
- Communication
- Feeding

별 progress percentage가 표시됩니다.

이것은 강력하지만 주의가 필요합니다.

장점:
- 발달 영역을 한눈에 확인

리스크:
- percentage가 발달점수로 오해될 수 있음

## 5. Track Milestones 화면

실제 Track 페이지는 Milestones와 Abilities를 구분합니다.

### Milestones
특정 행동/신체 체크포인트.

### Abilities
더 넓은 행동/발달 패턴.

이 구분은 매우 좋습니다.

예:
```
Milestone = 관찰 가능한 구체 행동
Ability = 여러 행동이 모인 상위 기능
```

## 6. 연령/도메인 taxonomy

실제 사이트:
- Baby on the Way
- Preemie
- NICU
- 0–2
- 2–4
- 4–6
- ...
- 6+ years

도메인:
- Motor
- Sensory
- Communication
- Feeding
- Tummy Time
- Play
- Social Emotional
- Executive Function

즉:
```
Age
×
Development Domain
×
Resource Type
```
의 다차원 탐색구조입니다.

## 7. Play 화면

Play에서:
- 현재 나이 기반 일반 활동
- 계정 생성 시 milestone progress 기반 개인 추천
- Tummy Timer
- 관련 domain 활동

을 제공합니다.

즉 personalization 단계가 명확합니다.

### 익명/미로그인
birthdate 기반 general recommendation

### 로그인
milestone progress 기반 personalized recommendation

좋은 **progressive personalization**입니다.

## 8. 활동→마일스톤 연결

Play 설명에서 실제로:
> Games from pediatric experts designed to help Baby reach milestones

라고 설명합니다.

따라서 구조는:

```
Milestone State
→ Recommended Activity
→ Play
→ Track Progress
```

입니다.

Kinedu와 유사하지만 Pathways는 **전문가 지식베이스/무료도구** 성격이 더 강합니다.

## 9. 조산/NICU

실제 전역 IA에 Preemie, NICU가 별도 존재합니다.

이것은 예외가 settings 속 buried option이 아니라 **최상위 탐색 경로**라는 점이 중요합니다.

## 10. Healthcare Provider용 별도 IA

사이트는 부모용과 별개로:
- Provider Home
- Brochures
- Checklists
- Online Courses
- Clinician Toolkit

을 제공합니다.

즉 동일 콘텐츠를:
```
Parent Experience
+
Clinician Distribution
```
두 채널로 사용합니다.

## 11. 직접 관찰로 수정된 기존 해석

기존에는 Pathways를 "발달 지식 플랫폼"으로만 봤지만 실제 웹은:
- 오늘 해야 할 것
- tracker
- weekly progress
- personalized play

를 갖춘 **행동형 product**입니다.
