## 분석 원칙

공개 저장소 검색 결과가 서비스명과 같다고 해서 공식 코드로 간주하지 않습니다.

공식 여부를 판단하려면 최소:
- 조직/회사 ownership
- 공식 사이트 연결
- README의 명시
- 배포 앱과의 연결

이 필요합니다.

따라서 BabyBilly clone 등은 코드 분석의 근거에서 제외했습니다.

## 현재 코드 수준으로 가장 분석 가치가 높은 대상

### Huckleberry ecosystem

비공식이지만 여러 독립 저장소가 같은 데이터 구조를 대상으로 하며 테스트까지 포함되어 있어, **데이터모델/실시간 동기화 패턴 연구**에는 충분한 가치가 있습니다.

다만 공식 구조라고 단정하지 않습니다.

## 향후 추가할 수 있는 방식

공식 앱 코드가 공개되지 않은 서비스는:
1. 공식 웹의 HTML/라우팅/네트워크 구조
2. 공개 웹 앱 JavaScript bundle
3. 개인정보처리방침
4. 도움말
5. 앱스토어 변경이력
6. 공개 SDK/API 문서
7. 공개 채용공고의 기술스택

등을 조합해 기술 구조를 추적할 수 있습니다.

단, 로그인 우회나 비공개 자원 접근은 하지 않습니다.
