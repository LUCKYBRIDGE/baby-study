# 분석 백로그

> 2026-11-08 기준. 이미 심층 분석한 서비스는 제외.

# 우선순위 A — 바로 분석할 가치가 큼

## Baby Tracker - Newborn Log (Nighp)
연구 이유:
- 오래된 대표 육아 트래커
- Apple Watch
- 최근 기록을 이용한 on-device AI 'What's Next'
- sleep/feed/diaper timing cue

비교 대상:
BabyTime, Huckleberry, 모미

## Hatch / Hatch Grow
연구 이유:
- 육아 기록과 하드웨어 연결
- 원터치 유축
- 소아과/수유상담가 export
- 스마트 기저귀 교환대/체중계 연계 사례

## The건강보험
연구 이유:
- 한국 영유아 건강검진 예약·문진·결과 흐름
- 공공앱 UX 분석

## E-GEN / 달빛어린이병원
연구 이유:
- 아기가 아플 때 '지금 갈 수 있는 곳' 탐색
- 평상시 기록과 응급/야간 의료기관 연결 가능성

- 고위험 UX 가드레일 분석

## Nara Baby / 기타 국내 트래커
- 한국어 UX
- 한국 부모의 기록 항목 차이

## Peanut
