# Pathways.org — 페이지·UI·UX·버튼 지도

## 1. Today

실제 Today 화면에 결합되는 성격:
- 오늘 할 activity
- Tummy Time progress
- Feeding
- Diaper
- Baby's Week
- Parent Pathways
- Baby's Progress
- New This Week

즉 dashboard가 **행동 + 기록 + 발달 + 부모교육**을 함께 오케스트레이션한다.

## 2. Play

두 층의 추천:
- 미로그인/기본: age-based
- 계정/진도입력 후: milestone-progress-based

```
Simple personalization
→ Deeper personalization
```

좋은 onboarding 전략이다.

## 3. Track

실제 tracker:
- Milestone
- Tummy Timer
- Diaper
- Feeding

발달만 별도로 떼지 않고 실제 육아행동과 함께 둔다.

## 4. Milestone UI

좋은 milestone row/card:
- 관찰 가능한 행동 문장
- 사진/영상
- 상태 선택
- 관련 activity

상태는 단순 Yes/No보다:
- Not Started
- Making Progress
- Achieved

처럼 progression으로 나타낸다.

## 5. Explore

방대한 전문가 정보는 Today에 모두 노출하지 않고 Explore에서 탐색한다.

이 분리가 중요하다.

```
Today = 필요한 것
Explore = 알고 싶은 것
```

## 6. Preemie / NICU

특수 상황을 settings 깊숙이 두지 않고 top-level age path로 제공한다.

사용자에게 "내 아이는 일반 경로의 예외"라는 느낌을 줄이지 않는다.

## 7. Provider Surface

부모용 이외에도 clinician toolkit/course 등 전문가용 surface가 존재한다.

같은 content graph를 다른 audience에 재사용한다.

## 8. UX 위험

progress percentage는 쉬운 시각화지만 발달 성적처럼 보이지 않도록 설명이 필요하다.

## 9. 미확인

- 네이티브 app 존재 여부/최신 구조
- multi-caregiver
- offline
- notification rules
