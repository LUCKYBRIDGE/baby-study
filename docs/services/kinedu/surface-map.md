# Kinedu — 페이지·UI·UX·버튼 지도

## 1. 웹 진입점

[A1]

상위 동선:
- Classes
- Blog
- Science
- How's my baby?
- Try free

즉 웹사이트가:
- acquisition
- evidence
- education
- assessment

을 동시에 담당한다.

## 2. Assessment landing

첫 화면에서 바로:
- 5분 미만
- 진단 아님
- 조산아 교정연령

을 알려준다.

이 세 문구는 사용자의:
- 시간 부담
- 의료적 오해
- 특수상황 불안

을 동시에 줄인다.

## 3. Preview 질문

가입 전에 실제 질문을 보여준다.

선택:
- I see this
- Not yet
- I'm not sure

### UX 의미
`I'm not sure`는 매우 중요하다.

강제 yes/no를 막아 입력 데이터 왜곡을 줄인다.

## 4. 본 Assessment

공식 설명:
- 32문항
- 5분 미만
- 나이에 따라 다른 질문
- 중간 저장
- 일부 항목은 reading에 미반영 가능

따라서 단일 긴 form이 아니라 **adaptive questionnaire**다.

## 5. 결과 화면

무료 결과:
- overall picture
- developmental age
- strongest area

상위 상품:
- 4영역
- 전체 milestone
- 반복 assessment
- progress curve
- emerging skills
- pediatrician summary

유료벽이 결과의 **설명 깊이와 장기 추적**에 놓인다.

## 6. Daily Activity

앱의 반복사용 화면은 "오늘 할 것" 중심으로 설계된다.

카드에 필요한 UX:
- 준비물
- 짧은 방법
- 왜 하는지
- 어떤 skill과 연결되는지
- 실행 후 관찰

## 7. Expert escalation

개인화 활동만으로 해결하지 않고 classes/전문 콘텐츠로 이어지는 별도 surface가 있다.

## 8. 잘한 UX

- 개인화 결과를 가입/구독 동기로 사용
- 질문이 추상적인 발달평가보다 관찰 가능한 행동 중심
- uncertainty를 인정
- 의료 경계를 반복 표시

## 9. 미확인

- 현재 네이티브 앱의 exact bottom tabs
- activity 완료 후 feedback 종류
- 추천 난이도 조정 UI
- offline
- caregiver multi-account permission
