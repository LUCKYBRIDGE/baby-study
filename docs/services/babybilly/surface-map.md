# 베이비빌리 — 페이지·UI·UX·버튼 지도

## 1. 공식 웹 상위 IA

[A1]

- 임신 준비
- 임신
- 육아
- 베동 모임
- 검색
- 입점/광고

웹 자체도 lifecycle navigation을 전면에 둔다.

## 2. Home의 핵심 UX

Home이 고정 기능 grid라기보다 현재 주수/월령에 따라:
- 성장 이미지
- 오늘 알아야 할 것
- 검사/건강
- 준비물
- 콘텐츠

가 바뀌는 방식이 핵심이다.

## 3. 일러스트/캐릭터

단순 장식이 아니다.

- 성장상태 시각화
- 매일 다시 열 이유
- 어려운 건강정보의 정서적 완화
- widget/브랜드 일관성

을 제공한다.

## 4. Health Record

공식 사이트에서:
- 아기 체중
- 복부둘레
- 머리둘레
- 엄마 체중

등의 기록과 평균범위 맥락을 제공한다고 설명한다.

UI는:
`입력 → 시기 기준과 비교`

구조다.

## 5. 베동

같은 주수/월령 기반 cohort community.

일반 게시판보다:
- 현재 검사
- 현재 고민
- 현재 구매
- 비슷한 발달단계

의 맥락이 맞는다.

## 6. Commerce

제품 추천도 stage context를 사용한다.

예:
```
곧 필요한 시기
→ 구매 카테고리
→ 추천 상품
```

홈에서 정보와 commerce가 경쟁하지 않도록 분리표시가 중요하다.

## 7. Widget

기존 공식 안내에서 D-day/아기 메시지/콘텐츠 연결형 widget이 확인된 바 있다.

앱을 열지 않아도 lifecycle context를 보여주는 surface다.

## 8. UX 강점

- 주수/월령이 모든 화면의 공통 언어
- 콘텐츠 타이밍이 좋음
- community relevance가 높음
- 정서적 브랜딩

## 9. 미확인

- 최신 네이티브 exact bottom nav
- tracking 입력 tap 수
- 공동양육 sync
- offline
- commerce와 editorial content의 내부 ranking rule
