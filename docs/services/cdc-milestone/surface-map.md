# CDC Milestone Tracker — 페이지·UI·UX·버튼 지도

## 1. Child Profile

행동:
- 아이 추가
- 사진
- 생년월일
- 다자녀 전환
- 조산 시 corrected age

## 2. Age Checklist

연령별 체크리스트는:
- play
- learn
- speak
- act
- move

등 실제 행동 중심이다.

각 항목에 사진/영상 예시가 연결된다.

## 3. Milestone item UX

좋은 구조:

```
행동 문장
[사진/영상 보기]
[관찰했음]
[아직]
→ 필요 시 concern guide
```

사용자가 문장의 의미를 해석하는 부담을 예시 미디어가 줄인다.

## 4. Tips / Activities

체크 후 "그래서 무엇을 할까?"를 간단한 활동으로 연결한다.

## 5. Act Early

우려가 있는 경우:
- 기다리기
보다
- 의료진과 상의하기

로 action을 명확히 한다.

## 6. Summary

[A1]

- PDF
- email

로 milestone summary를 외부에 전달할 수 있다.

앱 안 dashboard보다 **진료실 handoff**가 목적이다.

## 7. Well Visit Snapshot

진료에서 받은 내용을 다시 기록한다.

```
Home → Clinic → Home
```

양방향 흐름을 만든다.

## 8. Appointment / Reminder

발달선별검사 권장 시기와 doctor appointment를 관리한다.

## 9. UX 강점

- 사진/영상으로 입력 품질 향상
- 의료적 경계가 분명함
- export가 실제 행동으로 연결됨
- 경쟁/랭킹 요소가 없음

## 10. 미확인

- 최신 네이티브 exact navigation
- offline storage
- PDF 내부 필드 상세
- local notification implementation
