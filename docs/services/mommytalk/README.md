# 마미톡 — 서비스 정본 분석

> 유형: 임신·출산·육아 / 병원 연계 / 육아 기록 / 커뮤니티  
> 공개 제품코드: 확인 못함 [U]  
> 직접 검증: 공식 홈페이지·공식 커뮤니티 [A1]

## 1. 서비스 정의

마미톡은 **병원 초음파라는 강한 오프라인 접점을 앱 유입의 시작점으로 만들고, 임신기 정보와 출산 후 육아기록·통계·커뮤니티·커머스로 관계를 연장하는 생애주기 플랫폼**이다.

## 2. 핵심 사용자 여정

```
병원 초음파
→ 앱에서 영상 확인
→ 가족 공유
→ 주수별 정보
→ 출산
→ 육아 기록
→ 일/주 통계
→ 커뮤니티/쇼핑
```

## 3. 공개 코드/폴더 구조

공식 제품 repository는 확인하지 못했다.

따라서 내부 framework/DB/API를 단정하지 않는다.

## 4. 실제 확인된 육아 기록 범주

기존 "임신앱에 기록기능이 조금 있다"는 해석보다 깊다.

공식 기능 안내에서 확인된 범주:
- 모유
- 유축
- 분유
- 수면
- 소변
- 대변
- 이유식
- 체온
- 약
- 병원 방문
- 메모

기록 후 일간·주간 통계로 연결된다.

## 5. 가장 강한 진입점

일반 앱:
`검색/광고 → 설치`

마미톡:
`병원 검사 → 디지털 결과물 → 설치`

즉 실세계 이벤트가 activation trigger다.

## 6. 가장 잘 푼 문제

- 병원 초음파를 가족과 쉽게 공유
- 임신기 사용자를 출산 후에도 유지
- 고빈도 육아 기록을 한 앱 안에 흡수
- 전문가 감수로 건강정보 신뢰 확보

## 7. 위험

- 의료 신뢰와 커머스의 이해상충
- 커뮤니티 경험담의 의료정보화
- 임신/육아/쇼핑/커뮤니티가 홈에서 경쟁
- AI 이미지/의료영상 의미 혼동

## 8. 참고할 패턴

- Institutional Entry Point
- Real-world Event → App Activation
- Lifecycle Migration
- Expert Provenance
- Postpartum Tracker Transition
