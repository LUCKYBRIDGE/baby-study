# 마미톡 — 페이지·UI·UX·버튼 지도

## 1. 초기 진입 경험

핵심 CTA는 초음파 영상 확인/공유다.

사용자에게 "앱을 왜 설치해야 하나?"를 설명하기보다 이미 병원에서 생긴 결과물을 앱에서 받아보게 한다.

## 2. 임신기 화면군

개념적 구조:

```
Pregnancy Home
├─ 현재 주수
├─ 태아 성장
├─ 검사
├─ 초음파
├─ 전문가 콘텐츠
└─ 커뮤니티
```

## 3. 출산 후 화면군

```
Baby Home
├─ 빠른 기록
├─ 오늘 기록
├─ 일/주 통계
├─ 월령 콘텐츠
├─ 병원/건강
└─ 커뮤니티
```

출산은 단순 profile update가 아니라 Home mode 자체가 바뀌어야 하는 사건이다.

## 4. 빠른 기록 버튼

공식 기능 안내상 다양한 기록을 원터치 중심으로 제공한다.

좋은 UI라면 상위 빈도:
- 수유
- 수면
- 배변

을 가장 전면에 두고:
- 체온
- 약
- 병원
- 메모

를 secondary action으로 둬야 한다.

## 5. 통계

일간/주간 통계는 기록의 보상 역할을 한다.

```
Quick Log
→ Daily Summary
→ Weekly Pattern
```

## 6. 초음파 공유

기술 기능보다 정서적 UX가 중요하다.

- 영상 보기
- 가족 공유
- 과거 초음파 회고

가 pregnancy retention을 만든다.

## 7. 전문가 콘텐츠

건강정보 카드에는 이상적으로:
- 전문분야
- 감수자
- 업데이트일
- 근거

를 명확하게 보여주는 것이 좋다.

## 8. 커뮤니티

현재 주수/월령과 연결되면 질문 관련성이 높아진다.

다만 community answer와 expert answer는 같은 시각적 권위를 가지면 안 된다.

## 9. UX 강점

- 의료기관에서 자연스럽게 앱으로 이동
- 임신기 감정자산과 출산 후 utility 결합
- 기록 후 바로 통계가 돌아옴

## 10. 미확인

- 현재 앱 bottom nav
- 육아 기록 exact tap count
- caregiver sync
- 약 기록 확인 UX
- offline
