# 예방접종도우미 — 페이지·UI·UX·버튼 지도

## 1. 메인 서비스 카드

[A1]

공식 메인에서 큰 기능:
- 예방접종 관리
- 예방접종 정보
- 예방접종 알림터
- 위탁의료기관 찾기

즉:
`내 기록 / 공식 지식 / 알림 / 실행 장소`
가 분리되어 있다.

## 2. 예방접종 관리

실제 메뉴에서:
- 본인 내역조회
- 본인 일정
- 가족/자녀 관리

계열이 확인된다.

사용자에게 가장 필요한 화면은:
```
Upcoming
Completed
Overdue/Check
```
형식으로 재구성하면 더 읽기 쉽다.

## 3. 표준 예방접종 일정

공식 일정표는 source of truth 역할을 한다.

민간앱은 이를 복제하기보다:
- 현재 아이에게 해당하는 항목
- 공식 원문 link
- 마지막 검토일

을 보여주는 편이 안전하다.

## 4. 위탁의료기관 찾기

[A1]

국가예방접종 페이지에 직접 `위탁의료기관 찾기` CTA가 연결된다.

이것이 좋은 이유:
`정보 → 실제 접종 장소`
로 다음 행동이 바로 이어진다.

## 5. 사전알림

[A2]

절차상:
- 예진표에서 수신 동의
- 전화번호 기록
- 온라인에서 동의 확인/수정
- 국민비서 채널 사용 가능

즉 notification도 단순 앱 setting이 아니라 **공식 consent state**다.

## 6. 계절성 접종

인플루엔자 페이지는:
- 사업기간
- 연령
- 접종 횟수
- 이전 접종력

등 일반 정기접종보다 조건이 복잡하다.

Routine과 Seasonal UI를 분리하는 것이 좋다.

## 7. 오류 상태

검색 결과 중 실제 페이지에 "메뉴정보를 가져오지 못했습니다"와:
- 메인으로
- 이전으로

버튼이 제공되는 오류화면도 확인된다.

공공사이트의 실제 오류상태를 관찰할 수 있는 사례다.

## 8. UX 개선 관점

민간앱에서 앞단을 만든다면:
- 지금 필요한 접종 1~2개만
- 기간
- 완료 여부
- 기관찾기
- 공식 상세

순으로 단순화하는 것이 좋다.
