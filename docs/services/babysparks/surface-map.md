# BabySparks — 페이지·UI·UX·버튼 지도

## 1. 웹 IA

공식 메인에서 큰 축:
- Parenting App
- Online Parenting Classes
- Parent Resources

즉 child activity와 parent learning을 분리한다.

## 2. Register / Onboarding

[A1]

입력:
- child profile
- birth information
- due date when relevant

조산아 안내가 onboarding 단계에서 직접 노출된다.

이것은 고급설정에 숨기지 않고 추천 품질에 필요한 핵심정보로 취급한 것이다.

## 3. Daily Program

핵심 UX는 "검색"보다 "오늘의 프로그램".

좋은 activity card에 필요한 요소:
- 활동명
- 준비물
- 방법
- 시간
- 목표 milestone
- 완료/반응

## 4. Browse

추천 외에 부모가 필요에 따라 활동을 탐색할 수 있는 보조 구조.

추천만 있으면 통제감이 떨어지고, browse만 있으면 선택부담이 커진다.

따라서:
```
Default recommendation
+
Optional exploration
```
조합이 좋다.

## 5. Weekly Progress

일일 활동을 장기 progress로 묶어 돌려준다.

이 화면은 점수보다:
- 무엇을 자주 했는지
- 어떤 skill을 지원했는지
- 다음에 무엇을 해볼지

를 중심으로 보여주는 편이 좋다.

## 6. Parent Classes

child activity와 다른 UX가 필요하다.

- 수면
- 영양
- discipline
- potty training

등은 부모가 배우는 curriculum이므로 완료/진도 구조도 아이활동과 분리한다.

## 7. 기관용 Dashboard

[A1]

기관 상품에는:
- 여러 location
- 여러 caregiver
- 여러 child
- progress tracking
- 가족 공유

가 포함된다.

따라서 desktop은 **운영 dashboard**, mobile은 **현장 실행/가정 참여**로 역할이 다를 가능성이 높다.

## 8. 핵심 UX 문제

"오늘 20분"은 행동 기준을 단순하게 만든다.

다만 streak/미완료 경고를 강하게 하면 죄책감 UX가 될 수 있다.
