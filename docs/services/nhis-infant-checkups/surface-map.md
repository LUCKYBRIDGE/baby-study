# 영유아 건강검진 — 페이지·UI·UX·버튼 지도

## 1. 공식 안내 흐름

공식 PDF에서 실제 순서가 매우 명확하다.

### 01 검진기관 예약
- 검진기관 검색
- 모바일 The건강보험 경로 안내

### 02 웹 문진/발달선별 작성
- 인증 로그인
- 문진표
- 발달선별검사지
- 보호자 관계 확인 필요 시 별도 절차

### 03 검진
### 04 결과/상담
### 05 필요 시 전문기관 의뢰

## 2. 사전문진 UX

문진은 검진실에서 처음 생각하게 하는 것보다 집에서 미리 작성하게 한다.

장점:
- 시간 절약
- 부모가 관찰을 떠올릴 시간 확보
- 검진 효율 향상

## 3. 발달선별

[A1]

공식 안내상 일정 차수부터 발달선별검사지가 포함된다.

앱에서 가장 중요한 것은:
- 일반 milestone check
- K-DST 작성

을 동일 UI로 섞지 않는 것이다.

## 4. 검진기관 찾기

정보만 제공하지 않고 실제 provider discovery로 연결한다.

## 5. 결과

민간앱이 보조한다면 결과 화면에는:
- 공식 결과 원본
- 부모 메모
- 의사 설명
- follow-up
- 다음 검진

을 분리하는 것이 좋다.

## 6. 건강교육

검진 차수에 맞는 교육을 "관련정보"로 붙일 수 있다.

사용자에게 모든 건강교육을 한 번에 보여주지 않고 **현재 차수에 필요한 것만** 보여주는 것이 적합하다.

## 7. UX에서 복잡한 부분

보호자/보험등록 관계에 따라 온라인 문진 사용절차가 달라질 수 있다.

이런 행정 예외는:
- 왜 필요한지
- 현재 상태
- 다음 버튼

을 단계형 wizard로 표현하는 것이 좋다.

## 8. 미확인

- 결과 PDF/데이터 export UX
