# 국민건강보험 영유아 건강검진 시스템 분석

> 유형: 국가 영유아 건강검진 운영 시스템  
> 조사일: 2026-11-08  
> 공식: https://www.nhis.or.kr/

# 1. 핵심 가치

영유아 건강검진은 육아 앱의 일상기록과 **공식 의료·발달 평가가 만나는 지점**이다.

대한민국 국가건강정보포털 안내 기준으로 영유아 건강검진은 생후 14일부터 71개월까지 총 8회에 걸쳐 이루어진다.

또한 K-DST를 이용한 발달선별이 포함된다.

---

# 2. 실제 사용자 여정

공단 안내자료에서 다음 흐름을 확인할 수 있다.

```
검진 시기 확인
→ 검진기관 검색/예약
→ 웹 문진표
→ 필요한 시기 K-DST 작성
→ 검진
→ 결과
→ 필요 시 추가 평가/추적
```

좋은 육아앱은 이 흐름을 그대로 도와야 한다.

---

# 3. 앱이 추가할 수 있는 가치

공식 시스템을 대체하는 것이 아니라 **준비와 기억을 보조**한다.

## 검진 전
- 검진 가능 기간
- 예약
- 부모 질문 목록
- 최근 생활기록 요약

## 검진 당일
- 마지막 성장값
- 예방접종 기록
- 우려되는 발달 관찰
- 최근 증상

## 검진 후
- 부모가 받은 설명 기록
- 후속 일정
- 다음 검진

---

# 4. K-DST와 일반 마일스톤 체크의 구분

매우 중요하다.

- 일반 앱 체크리스트: monitoring
- K-DST: 국가 영유아검진에서 사용하는 발달선별
- 전문 평가: clinical evaluation

일반 앱이 K-DST를 흉내 내어 자체 점수를 만들고 동일한 의미처럼 표현하면 안 된다.

---

# 5. 검진별 교육 주제에서 얻는 정보구조

국가건강정보포털은 검진 과정에서:
- 영양
- 안전사고 예방
- 안전수면
- 구강
- 대소변 가리기
- 전자미디어 노출
- 정서/사회성
- 개인위생
- 취학 전 준비

등을 시기별로 다룬다.

이 목록은 **월령별 부모 교육 커리큘럼**의 공식적인 힌트가 된다.

---

# 6. 진료용 요약의 필요성

육아 앱이 가장 가치 있게 연결할 수 있는 지점:

```
최근 2주
수유 / 식사
수면
배변
체온/질병
약
성장
발달관찰
부모질문
```

을 한 장으로 만드는 것이다.

모든 원자료를 의사에게 보여주는 것보다 **요약 + 이상구간 drill-down**이 적합하다.

---

# 7. 가져올 패턴

## Eligibility Window
단일 날짜가 아니라 검진 가능한 기간.

## Pre-visit Questionnaire
평소 기록을 문진 준비로 재사용.

## Doctor Question Inbox
평소 떠오른 질문을 검진 전까지 누적.

## Follow-up Task
검진 결과를 읽고 끝내지 않고 후속 행동을 일정화.

영유아 검진은 별도의 '병원 메뉴'가 아니라 **매일의 육아 기록이 공식 건강관리로 연결되는 주요 출구**로 설계해야 한다.
